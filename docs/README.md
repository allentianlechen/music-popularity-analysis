# Project docs

This folder keeps planning notes and historical implementation logs away from
the runtime files at the repository root.

## Files

- `PROJECT_PLAN.md`: Original implementation plan and task breakdown.
- `IMPROVEMENTS.md`: Improvement checklist and security/code-quality notes.
- `projectProgress.md`: Longer progress record from earlier project work.
- `preview.html`: Static design preview kept for reference.

For day-to-day setup and deployment, start with the root `README.md`.
